
#  Magic Donuts

Sistema de gerenciamento e loja virtual para uma confeitaria especializada em donuts.

**Projeto de Informática**

- **Turma:** RGI61
- **Desenvolvedoras:** Amanda Ramos e Victória Silva

---

## Sobre o Projeto

O **Magic Donuts** é um sistema web desenvolvido para uma confeitaria fictícia especializada na produção e comercialização de donuts.

O projeto tem como objetivo oferecer uma solução para o gerenciamento interno do estabelecimento, facilitando o controle de produtos, variações, fornecedores, entradas de mercadorias, estoque, vendas e relatórios.

Além da área administrativa, o sistema também conta com uma interface voltada aos clientes, permitindo visualizar os produtos disponíveis, adicionar itens ao carrinho e realizar pedidos.

A proposta é integrar a gestão da confeitaria com a experiência de compra dos clientes em uma única aplicação.

---

## Funcionalidades

### 🔐 Área Administrativa

- Dashboard com informações gerais do estabelecimento.
- Cadastro, edição e gerenciamento de produtos.
- Gerenciamento de categorias e variações.
- Cadastro e gerenciamento de fornecedores.
- Registro de entradas de mercadorias.
- Controle de estoque e movimentações.
- Registro e gerenciamento de vendas.
- Geração de notas fiscais demonstrativas.
- Consulta de relatórios gerenciais.
- Exportação de relatórios em formato CSV.
- Controle de acesso por usuário e perfil.

### 🛒 Loja Virtual

- Página inicial com apresentação da confeitaria.
- Catálogo de produtos.
- Visualização dos produtos e suas variações.
- Carrinho de compras.
- Finalização de pedidos.
- Área de login e cadastro de clientes.
- Consulta de pedidos realizados.

### 📦 Controle de Estoque

- Atualização automática do estoque conforme as entradas e vendas.
- Registro das movimentações de mercadorias.
- Controle de disponibilidade dos produtos.
- Impedimento de compras quando não há estoque disponível.

## Arquitetura do Sistema

O projeto utiliza o padrão arquitetural **MVC (Model-View-Controller)**, responsável por organizar o código em três camadas:

- **Model:** responsável pela comunicação com o banco de dados e pelas operações relacionadas às informações do sistema.
- **View:** responsável pela apresentação das interfaces e exibição dos dados.
- **Controller:** responsável por receber as solicitações, executar as ações necessárias e conectar Models e Views.

Essa organização facilita a manutenção, a reutilização e a compreensão do código.

---

## 🗄️ Banco de Dados

O sistema utiliza o MySQL para armazenar e organizar as informações da confeitaria.

O banco de dados `magicdonuts` contempla informações relacionadas a:

- Usuários e permissões.
- Clientes.
- Produtos, categorias e variações.
- Estoque e movimentações.
- Fornecedores.
- Entradas de mercadorias.
- Vendas e respectivos itens.
- Pedidos.
- Notas fiscais demonstrativas.

---

## 🎨 Identidade Visual

O Magic Donuts possui uma identidade visual moderna e delicada, utilizando principalmente tons de lilás, roxo, creme e bege.

A proposta visual busca transmitir a personalidade da confeitaria, proporcionando uma experiência agradável e intuitiva tanto na área administrativa quanto na loja virtual.
